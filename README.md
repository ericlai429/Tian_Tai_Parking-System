# 🏗️ 天泰營造與勤務管理系統 (Tian Tai Management System)

> **使用單位**：天泰營造  
> **執勤單位**：飛龍保全 / 中華飛龍物業  
> **GitHub 專案庫**：https://github.com/ericlai429/Tian_Tai_Parking-System  
> **線上發布站點**：https://ericlai429.github.io/Tian_Tai_Parking-System/  

---

## 🌟 核心功能亮點

### 1. 📅 天泰三總 現場執勤排班表 (115年9月份)
* **100% 覆蓋現場排班**：自 9/8 正式進駐執勤，全月總工時 **276 小時**，每日 12H (A班 07:00~19:00)。
* **人員排班明細**：
  * **賴鯤仲** (固定日班)：192 小時 (16 天)
  * **葉榮東** (機動日班)：60 小時 (5 天代班)
  * **賴宗興** (機動日班)：12 小時 (9/9) ＋ **9/11 桃紅色標記代班賴鯤仲**。
* **多視圖切換**：
  * 全月排班矩陣表 (附週末例假日黃底、桃紅特殊代班與排休標記)
  * 人員詳細執勤工時卡片
* **Excel 雙向支援**：支援一鍵匯出與匯入標準 Excel 班表。

### 2. 🅿️ 智慧停車放行管制系統
* **Google 雲端試算表對接**：
  * 線上試算表：https://docs.google.com/spreadsheets/d/1QJkm5rNHtyQN84awlHWoz4n9jE8NFogk4I4k4x3FPok/edit?gid=239543721#gid=239543721
  * 支援由 **Admin** 線上編輯試算表，現場系統支援一鍵雲端即時同步。
  * 預載官方「工地工區大門－車輛管制」最新 14 筆官方車冊 (品管、工地主任、專案經理、機電包商負責人、建築師、總經理座車等)。
* **超快車牌秒查核對**：
  * 模糊搜尋與智慧去除空格/破折號比對。
  * 准予放行 (PASS - 綠色發光與彩帶回饋)、待查核 (PENDING) 與未通過 (DENIED)。
* **靈活匯入匯出**：支援匯入全新 Excel 車輛清單，自動辨識多種車牌與身分欄位。

### 3. 📊 總覽戰情指揮室
* 今日值勤保全即時卡（自動偵測當日排班人員與聯絡電話）。
* 車牌秒查驗證站。
* 雲端與本地同步狀態監控。
